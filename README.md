## 搬瓦工支持哪些付款方式

先给个直接答案：搬瓦工目前支持四种付款方式——

- **支付宝（Alipay）**：国内用户用得最多，扫码付，系统自动按当天汇率换算成美元
- **银联（UnionPay）**：国内银行卡都能用，包括借记卡和信用卡
- **PayPal**：有账户的话也能用，美元结算
- **信用卡（Credit Card）**：Visa / MasterCard / AMEX，直接美元付

讲真，支付宝和银联是大多数国内人首选。支付宝最顺手，直接手机扫码就行；如果偶尔支付宝那边出点问题，切换成银联也完全没问题，两个都是人民币付、系统换成美元结算，汇率按当天实时价来。

点击 Complete Order 之后跳转到支付宝付款页面，出现一个二维码。掏出手机，打开支付宝，扫码，付款，搞定。付款完成后系统几分钟内自动开通服务器。

## 注册时几个坑提前告诉你

**关掉梯子再注册**。这是最常见的翻车点。挂着代理注册，系统检测到 IP 地址和你填的国家对不上，直接判欺诈，砍单。关掉，用真实的国内网络环境注册就行。

**邮箱要能收到邮件**。购买后服务器信息（IP 地址、SSH 端口、初始密码）会发到你的注册邮箱，Gmail 之类的都可以，不要用临时邮箱。

**支付宝付款如果跳转失败**。偶尔会碰到点了 Pay Now 之后页面没动静——等一会儿刷新，或者直接切换成银联付款也一样，最终效果完全相同。

## FAQ

**Q：搬瓦工支付宝付款显示"系统繁忙"怎么办？**

这种情况偶尔出现。可以稍等几分钟再试，或者直接切换成银联付款，两种方式结果完全一样，不影响开通速度。

**Q：支付宝付款是人民币还是美元？**

是人民币付，但按美元计价、按当天汇率换算。比如某个套餐 $49.99，你支付宝显示的是对应的人民币金额，结算汇率实时浮动。

**Q：搬瓦工支付宝可以用来给余额充值吗？**

目前余额充值不支持支付宝，只能用 PayPal 或信用卡充值余额。但直接购买和续费是支持支付宝的，大多数人用直接买套餐或到期续费的方式就够了。

**Q：注册信息要填真实地址吗？**

对，地址填真实的。国家选中国，省市尽量真实，不用填精确门牌号，但明显假的信息（全填 XXX 之类）会被判欺诈，可能导致砍单。

**Q：买了之后可以换机房吗？**
